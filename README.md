﻿# Library Tracker

## Project Overview

Library Tracker is a Java console application for managing library books.

## Features

- Add books.
- Display all books.
- Search books by title.
- Remove books by ID.
- Save books to a JSON file.
- Load saved books automatically.

## Technologies

- Java
- Git
- GitHub
- JSON

## Project Structure

- src/Book.java
- src/BookStore.java
- src/Main.java
- data/books.json
- docs/
- README.md

## How to Run

Compile the project:

    javac -d src src/Book.java src/BookStore.java src/Main.java

Run the application:

    java -cp src Main

## Application Menu

1. Add Book
2. List Books
3. Search Book
4. Remove Book
5. Exit

## Data Storage

Book information is stored in data/books.json.

## Collaboration

The project uses GitHub, feature branches, commits, and pull requests.

## Current Limitations

Borrowing and returning books are not implemented.
